# BITSTREAM
This is a compact pcb for a custom mp3 player
## Features
- A 8Ω, 2W speaker
- A audio jack for wired earphones
- A tft display screen
- a dfplayer mini and a micro sd car to upload your music
- 4 buttons to select your music
- a rotary encoder to adjust the volume
- an arduino nano
